# Socratic Mentor

An AI tutor that doesn't give answers—it asks questions. Unlike traditional chatbots that hand you solutions, Socratic Mentor guides you through discovery, helping you understand the "why" behind every concept through guided inquiry, critical thinking, and step-by-step reasoning.

## Tech Stack

- React + TypeScript
- Vite
- Express
- Google Gemini API
- Groq API
- Tailwind CSS
- Firebase (optional)
- Render (deployment)
